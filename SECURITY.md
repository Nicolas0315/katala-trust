# Security Policy

## Supported versions

The `main` branch of `katala-trust` is the supported public surface.

## Reporting a vulnerability

Please open a private GitHub security advisory on
https://github.com/Nicolas0315/katala-trust
or email the maintainer listed in the GitHub profile.

Do not file public issues for unpatched vulnerabilities.

## Scope notes

This repository is a verification sidecar. It does not ship a Next.js auth app.
Reports about dormant private-monorepo UI/auth code are out of scope here.
